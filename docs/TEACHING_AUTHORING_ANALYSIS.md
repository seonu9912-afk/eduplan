# 첨부 운영계획의 내용 분석과 작성 지원 설계

분석 대상: 사용자가 제공한 2026학년도 2학기 국어과 교수학습 및 평가 운영 계획 HWPX의 1·2·3학년 교수학습표와 평가 세부계획.

사용자 정정: 목적은 파일 다운로드 구현을 앞세우는 것이 아니라, 실제 계획을 어떤 내용과 논리로 작성하는지 파악해 EduPlan의 작성 기능을 설계하는 것이다. 아래는 원문에서 확인한 내용과 그에 따른 설계 판단을 구분한 분석이다. 완성 문서만으로 교사의 실제 작업 순서를 단정하지 않는다. 문서의 학교별 방침을 모든 학교에 적용되는 현행 규정으로 간주하지 않는다.

## 1. 문서가 표현하는 계획의 관계

문서의 중심은 성취기준에 근거하여 수업을 운영하고 그 과정과 결과를 평가하는 학기 계획이다.

성취기준 ↔ 단원·학습 주제 ↔ 주차별 교수학습활동 ↔ 수업 중 확인·피드백 ↔ 성적에 반영할 평가과제 ↔ 평가요소·채점기준

이 관계는 일대일이 아니다. 하나의 단원이 여러 주에 걸치고, 하나의 평가과제가 여러 주·단원·성취기준에 연결될 수 있다. 같은 성취기준을 연결했다는 사실만으로 특정 수업이 특정 평가의 준비·실시·피드백 과정이라는 관계까지 표현되지는 않는다.

### 원문 사례: 1학년 ‘단어의 짜임과 새말’

- 성취기준: [9국04-02] 단어의 짜임을 분석하여 새말 형성의 원리를 이해한다.
- 수업: 9월 7~11일 개념과 짜임 분석 → 14~18일 형성 원리 탐구 → 21~25일 새말을 우리말로 다듬고 설명. 10월 5~9일에도 해당 수행평가 연계 표시가 있다.
- 평가 영역: ‘단어의 짜임과 새말’, 시기 9~10월, 4차시, 영역 만점 100점, 학기 반영비율 50%.
- 채점: 개념 이해 / 단어 짜임 분석 / 새말 원리 탐구 / 자료·표현, 각 25점. 각 요소 안에 25·20·15·10점의 판단 기준이 있다.

설계상 필요한 작성 지원: 성취기준을 선택하고, 학생이 할 활동과 확인할 증거를 구체화하며, 여러 주의 수업을 같은 평가과제의 준비·실시·피드백에 연결한다. 평가요소별로 실제 관찰할 수행과 점수 차이를 작성한다. 100점(과제 만점), 50%(학기 반영비율), 4차시(과제 운영), 여러 주의 수업기간을 서로 다른 값으로 다룬다.

### 원문 사례: 1학년 ‘한 학기 한 권 읽기’

- 8월 31일~9월 4일 도서 선정, 10월 19~23일 독서 기록, 11월 2~6일 프로젝트 연계, 1월 26~29일 결과물·발표가 수업표에 나타난다.
- 평가 요약의 시기는 ‘수시’이고 반영비율은 50%이다. 한 날짜에만 놓이는 평가가 아니다.
- 세부 채점표의 진행 단계는 책 읽기 → 독서 활동지 → 독서 프로젝트이다. 독서 프로젝트 단계에는 ‘참여의 성실성’과 ‘표현의 적절성’ 두 요소가 들어간다.

필요한 구조: 평가과제 → 진행 단계 → 평가요소 → 점수별 판단 기준. ‘진행 단계 3개’와 ‘채점 요소 4개’를 구분해야 한다. 학생의 참여·산출물·표현 등 무엇을 증거로 볼지 드러나야 한다.

## 2. 교수학습계획에 필요한 내용

| 내용 | 작성 시 답해야 할 질문 | 원문에서 확인한 의미 |
| --- | --- | --- |
| 학년도·학기·학년·과목·담당교사 | 누구의 어떤 기간 수업인가? | 학년별 계획, 복수 지도교사, 주당 3시간 |
| 성취기준과 단원 | 학생이 무엇을 할 수 있게 되어야 하는가? | 기준 코드와 문장을 단원/여러 주에 연결 |
| 월·주·실제 기간 | 어떤 수업을 언제 배치하는가? | 월을 넘는 31~4일, 방학 후 1월 재개 등 |
| 학생의 학습활동 | 그 기준을 배우기 위해 무엇을 하는가? | 분석하기·비교하기·토의하기·기록하기·고쳐 쓰기 |
| 수업방법 | 어떤 방식으로 배우게 하는가? | 탐구·협력학습·개별 독서·과정 중심 쓰기 등 |
| 평가방법 | 학습 과정을 무엇으로 확인하는가? | 관찰·형성·자기·동료평가, 기록장·보고서 등 |
| 수업-평가 연계 주안점 | 어떤 활동에서 무엇을 확인하고 지도하는가? | 예: 갈등 파악 과정 관찰, 독서 질문과 갈등 분석 평가 |
| 평가과제 연결 | 이 수업이 어느 평가의 어떤 과정인가? | ‘★수행평가 연계(과제명)’로 반복 표시 |
| 교육활동·비고 | 수업 운영에 영향을 주는 활동은 무엇인가? | 공휴일·개학·체험주간, 인성/민주시민교육 표시 |

원문의 ‘평가요소’ 열에는 학습활동 문장이 다수 들어 있다. 이 내용을 세부 채점표의 평가요소와 동일한 데이터로 취급해서는 안 된다. 화면에서는 ‘학생 학습활동’과 ‘평가에서 확인할 내용’을 이해할 수 있게 안내하고, 학교 서식에 맞는 열 제목으로 표현할 수 있어야 한다.

학교 교육활동 주간은 성취기준을 ‘-’로, 학기 마무리는 ‘전 성취기준’으로 기재한다. 모든 행을 정규 단원으로 간주하여 특정 성취기준 누락 오류를 발생시키는 방식은 맞지 않는다. 다만 ‘전 성취기준’이 공식 기준 하나를 뜻하는 것은 아니므로 전체 참조와 개별 기준을 구분한다.

주당 시수만으로 공휴일이 낀 주의 실제 국어 차시를 확정할 수는 없다. 실제 수업 요일·시간표 또는 교사의 배당 확인이 필요하다. 학사일정 변경 시 영향받는 주를 제시하되 작성한 수업을 임의 이동하거나 차시를 확정하지 않는다.

## 3. 평가계획의 서로 다른 층위

| 층위 | 필요한 내용 | 구분할 점 |
| --- | --- | --- |
| 교과·학기 운영 방침 | 목적, 기본 방향, 평가 구성, 실시 원칙, 개별 역할, 미응시/학적변동/지원 대상 처리 | 학교 규정과 교과 특성에 따른 내용; 단순 고정 문구로 일괄 배포하지 않음 |
| 평가 전체 구성 | 정기시험·수행평가 등 영역, 과제명, 시기, 만점, 비율, 기준, 단원 | 요약표는 과제 상세에서 모아 보여주어 중복 입력을 줄임 |
| 개별 평가과제 | 성취기준, 학생이 할 일과 결과물, 운영 차시, 평가방법, 역량, 준비·실시·피드백 수업 | 서식에 독립된 과제 설명 칸이 없어도 작성 도구에서는 명확히 설계할 필요가 있음 |
| 과제 진행·채점 | 진행 단계, 단계별 평가요소, 요소 배점, 점수별 구체적 판단 기준 | 진행 단계와 우수/보완 등 평정수준을 구분 |
| 성취기준별 성취수준 | 해당 기준을 어느 정도 수행하는가에 대한 설명 | 기준별 A~E 또는 상·중·하 등 가변 구조 |
| 학기 단위 성취수준 | 그 학기에 다루는 여러 기준을 종합한 수행 설명 | 개별 과제의 채점 기준과 구분 |
| 성취율·성취도 | 학기 평가 결과를 성취도로 해석하는 구간 | 원문 A~E 구간을 학교급/운영방식과 무관하게 강제하지 않음 |

원문의 3학년 독서 과제는 성취기준별 수준이 상·중·하이고 학기 단위 수준은 A~E이다. 점수별 채점 기준은 다시 25·20·15·10점이다. 이 세 가지를 하나의 ‘수준’ 입력으로 합치면 작성 논리가 무너진다.

형성·관찰·자기·동료평가는 수업 중 학습 확인에 자주 등장한다. 모든 주차의 평가방법을 별도 성적 반영 항목으로 자동 생성하지 않는다. 또한 관찰평가나 형성평가라는 방법 이름만으로 성적 반영 여부를 판단하지 않는다. 원문처럼 수행평가 과제 내부에서 여러 방법을 함께 쓸 수 있다.

최하점 합계 40점은 각 요소의 최하점 합이다. 이를 결시·미제출 학생의 인정점 또는 기본점으로 자동 적용하지 않는다. 그런 처리는 별도의 학교 규정과 교사 확인 대상이다.

## 4. 단순 항목 추가로 해결되지 않는 검토

문서 내용의 오류를 자동으로 단정하거나 수정하지 않고 교사가 확인할 근거와 연결 위치를 제시한다.

- 1학년 수업표의 [9국01-07]은 ‘토의에서 … 대안을 마련하고 문제를 해결한다’인데, 독서 수행평가 상세에는 같은 코드에 ‘자신의 삶과 경험을 바탕으로 정서를 … 표현하는 글을 쓴다’가 적혀 있다.
- 같은 학년의 [9국05-02]도 수업표에는 ‘갈등의 진행과 해결 과정 …’, 독서 과제에는 ‘인간의 성장을 다룬 작품 …’로 서로 다른 문장이 있다. 공식 원문 대조가 필요하며, 파일의 문장을 검증된 성취기준 DB로 일괄 수입하면 안 된다.
- 학년 사이에서는 같은 코드가 다른 교육과정에서 다른 뜻일 수 있다. 예컨대 1학년과 3학년의 [9국04-02]는 문서상 내용이 다르다. 교육과정 버전을 구별한 뒤 비교해야 한다.
- 2학년 독서 과제의 성취기준은 책 선정과 읽기 과정의 점검·조정인데, 세부 채점 요소는 독서 퀴즈, 경험 관련 쓰기, 상상하여 쓰기, 편지 쓰기이다. 이것만으로 부적합하다고 단정할 수는 없지만, 책 선정·점검·조정의 수행 증거가 어떤 활동/요소에서 확인되는지 교사가 설명할 수 있어야 한다.
- ‘잘 작성/다소 미흡/매우 미흡’과 같은 채점 문장은 판단의 차이를 구체화할 작성 안내가 필요하다. 도구가 임의의 정답 기준을 확정하는 대신, 예를 들어 근거·정확성·구체성·과정 기록 중 무엇으로 차이를 판단할지 묻도록 설계한다.
- 성취기준 연결 누락, 평가 전 관련 학습 기회 미확인, 과제 연결 없는 평가, 배점/비율 불일치, 요약과 상세의 시기·명칭 차이를 확인한다. 학습 기회 미확인은 곧바로 오류로 단정하지 않는다.

## 5. 작성 흐름의 재설계 기준

문서 배치 순서를 입력 순서로 강제하지 않는다. 수업부터 설계하거나 평가과제부터 설계해도 서로 연결할 수 있어야 한다.

1. 학기 기본 조건과 교육과정·성취기준을 확인한다. 주당 시수는 출력 서식 안이 아니라 수업 운영 설정에 둔다.
2. 단원/학습 주제와 평가과제를 설계한다. 과제별로 기준, 학생 활동·결과물, 진행 단계, 평가요소와 채점 근거를 구성한다.
3. 학사운영을 참고한 주차 목록에 수업을 배치한다. 같은 과제의 준비·실시·피드백을 여러 주에 연결하고 이어지는 수업을 편집한다.
4. 수업방법·학습 확인 방법·연계 주안점을 작성한다. 연결된 평가과제와 해당 기준을 보며 중복 타이핑을 줄인다.
5. 학기 전체의 평가 구성·성취수준·방침을 정리한다. 학교 공통 내용은 출처/적용 범위를 확인해 재사용하고 과거 계획을 조용히 바꾸지 않는다.
6. 연결 관계와 내용의 일관성을 검토한다. 출력 형식은 이 내용을 표현하는 마지막 단계다.

## 6. 이번 보완에서 구현한 작성 지원 (2026-11-11)

- 교수학습계획의 한 행은 한 주 또는 연속된 수업이다. 같은 단원명과 평가과제를 여러 행에서 사용할 수 있다. 수업·학교 활동·성찰/정리 행을 구분한다.
- 주차별 수업과 평가과제를 여러 개 연결하고 각 연결에 준비/실시/피드백, 과제 진행 단계를 지정한다. 수업과 평가 양쪽에서 연결하며 검토 화면에서 서로 이동한다.
- 평가과제의 학생 수행, 결과물/활동 기록, 실제 진행 단계, 단계별 복수 채점 요소, 평정수준과 점수별 판단 기준을 구별한다. 각 채점 요소에 해당 과제의 성취기준과 증거를 연결한다.
- 성취기준별 수준 설명은 실제 기준 ID에 연결할 수 있고, 기존 코드/수준 자유기술은 유지한다. 학기 단위 수준과 성취율·성취도는 별개 항목으로 남긴다.
- 검토 화면은 과제별 준비→실시→피드백 수업, 기준→채점 요소→증거를 함께 보여준다. 과제 연결/학습 기회/증거 누락 및 같은 교육과정 범위에서 코드가 같고 문장이 다른 등록 기준을 확인 대상으로 표시한다. 이 검토는 문장의 타당성을 판정하거나 공식 원문과 자동 대조하지 않는다.
- 주당 시수를 수업 운영 설정에 배치했다. 학사일정의 실제 수업일이 있는 주를 초안으로 추가하며, 날짜가 명시된 기존 행과 겹치는 주는 건너뛴다. 실제 과목 차시는 빈칸으로 두며 시간표를 가정하지 않는다. 날짜 없이 자유문자로 작성한 기존 행은 자동 중복 판정 대상이 아니다.
- 기존 문서는 새 선택 필드 없이도 유효하다. 과제 삭제는 그 과제의 연결만 제거한다. 단계 삭제는 수업/채점 내용은 보존하고 단계 연결만 해제한다. 과제 단독 복사는 단계·채점 ID를 새로 만들고 수업 연결은 교사가 새로 지정한다. 계획 전체 복사와 이력 복원은 내부 연결을 함께 보존한다.
- 인쇄/HWPX도 같은 작성 데이터를 사용해 연결, 과제 설명, 단계, 증거를 담는다. 출력 성공을 내용 설계의 적절성 보장으로 취급하지 않는다.

확인 사례는 독서 과제 한 개, 세 주의 준비/실시/피드백, 세 진행 단계와 네 채점 요소(프로젝트 단계에 참여도·표현력 두 요소)이다. DB 참조 검사, 실제 화면 작성·저장·재접속·복원·복사 검증 결과는 TESTING.md에 기록한다.

남은 범위: 학교 공통 방침의 별도 관리·배포, 공식 성취기준 원문 데이터 검증, 실제 과목 시간표에 따른 차시 배당, 학교별 임의 HWPX 서식 자동 분석/수입. 학교의 규정·평가 구성·수준 체계를 자동 확정하지 않는다.
