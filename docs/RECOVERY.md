## 데이터 백업 및 운영 반영 조건

운영 Supabase의 `public` 테이블 21개와 행 40개를 한 번의 읽기 조회로 확보했습니다. 컬럼·제약·인덱스·트리거·RLS·함수 목록, 16개 적용 이력, SQL 마이그레이션 원본을 포함합니다. Auth 계정·토큰은 운영 서비스에 남아 있으며 이 내보내기는 전체 Supabase 인스턴스 복구본이 아닙니다. 저장된 학교 자료를 GitHub 및 미리보기 소스와 분리했습니다.

쓰기가 가능한 GitHub 연결에서 복구 브랜치를 게시한 뒤 운영 프로젝트의 Git 연동을 구성합니다. 실제 Supabase 계정으로 인수 테스트를 마친 뒤 운영 전환 영향을 확인하고 사용자 승인을 받습니다.
