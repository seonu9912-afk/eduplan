## 2. 독립적으로 판단해 구현한 개선

- **화면–저장–출력 계산 일치:** DB와 Excel 모두 `학기별 주수 → 연간 주수 → 기본 16주`의 동일한 우선순위를 사용한다. 기존 문서는 일괄 재계산하거나 덮어쓰지 않는다.
- **기존 불일치의 안전한 정정:** 로드한 버전과 화면 데이터의 버전이 같은 경우 저장 시수와 문서 계산을 비교해 차이를 안내한다. 사용자가 편성값을 검토하고 `현재 편성 다시 저장`을 눌러야 연계 시수가 갱신된다. 불일치가 남은 상태의 새 확정은 막는다.
- **저장 실패 복구:** 네트워크 예외 후에도 입력을 보존하고 재시도할 수 있다. 중복 저장 요청을 막고, 저장 중 추가 입력은 다음 버전으로 저장한다. 저장 실패·입력 오류를 단순한 ‘저장 대기’와 구분한다.
- **편집 보호:** 새 과목을 받더라도 현재 편집기를 유지한다. 입력 중인 셀도 미저장 상태에 포함하며 페이지 이탈 경고를 제공한다. 최신본 재조회는 미저장 내용 폐기 여부를 확인한다. 실행 취소·재실행을 기본 입력 단계에 다시 노출한다.
- **확정의 정합성:** 새 버전 확인 RPC에서 plan/document 버전을 함께 검사하고 저장과 동일한 잠금 순서로 확정한다. 이전 확정본은 변경하지 않는다. 기존 RPC 서명은 구 클라이언트 호환용으로 남기되 스냅샷 생성은 직렬화한다.
- **선택과목 중복 방지:** 입력 UI·클라이언트 검증·DB에서 같은 학기의 중복 선택 배정을 막는다. 기존 중복 문서는 학생 이수합계를 확정 가능한 값으로 표시하지 않는다.
- **붙여넣기·취소:** 빈 마지막 셀을 0으로 반영하고, 범위 밖·교과/창체 경계·잘못된 값은 전체 붙여넣기를 거절한다. 붙여넣은 값이 blur로 되돌아가지 않으며 Escape는 입력을 취소한다.
- **복구 자료 보존:** 미등록 과목의 비어 있지 않은 셀을 보존하고 검증 오류로 알린다. 기존 저장값을 17주로 나눌 때 순환소수 대신 주당 몫과 조정 잔여값을 사용한다. 기존에 저장된 소수 문서 자체는 바꾸지 않는다.

## 3. 기존 요구사항을 근거로 구현한 사항

- `Curriculum`의 과목 구성 → 시수 배당 → 검토·확정 세 단계와 입학년도별 운영 제외를 유지한다.
- 교과·과목 직접 편집, 주당 입력·학기 합계 직접 조정·자동 계산을 유지한다. 기본 단계에서 학기 합계 모드를 다시 사용할 수 있다.
- 초등 6개년/12학기, 중·고 3개년/6학기를 UI와 출력에 반영한다. 초·고교 창체 과목도 설정 화면에 표시한다.
- 학점 편성표는 학기별 학점을 직접 입력하고 학점으로 출력한다. 기존 시간 단위 고교 편성표의 단위는 바꾸지 않는다. 서로 다른 단위가 섞인 운영표의 Excel 합산은 거절한다.
- 중학교 기준 비교를 초·고교에 적용하지 않는다. 학교 편성 기준 주수는 법정 학기 주수를 뜻하지 않는다. 법정 적합성 인증은 추가하지 않는다.
- 기존 과목·입학년도·시수·이력·확정본을 삭제하는 마이그레이션은 없다. 운영 DB 변경과 운영 배포는 수행하지 않는다.

- Playwright 실습 화면 검증: 과목 구성 보완 후 로컬 6개 통과(약 1.1분), 아래 공개 Preview에서도 6개 통과(35.8초). 직접 입력·주수 변경·합계 수정·재조회, 마지막 빈 열 붙여넣기, Escape 취소, 실패 후 재시도, 저장 중 입력, 초등 6학년·고교 학점·390px 모바일, 두 창 버전 충돌과 폐기, 여러 교과의 실제 Excel 다운로드를 확인했다.
- 공개 Preview 브라우저에서도 주당 3시간·17주를 입력해 51시간 계산 및 새로고침 후 보존을 확인했다. 원격 Playwright의 첫 시도는 실행 환경의 NSS DB 접근 제한으로 인증서 오류가 났으며, 기존 `docs/TESTING.md` 절차에 따라 해당 DB 디렉터리 쓰기 권한을 부여한 재실행에서 통과했다. 인증서 검증은 끄지 않았다.
- DB 테스트는 구 SQL로 48시간을 저장해 오류를 먼저 재현하고, 새 마이그레이션 적용 자체는 기존 48을 그대로 두는지 확인한다. 명시적으로 재저장한 뒤 51시간, 문서 재조회 일치, 실패 시 기존 값 보존, 과거 확정본 보존을 검사한다.
- PGlite는 PostgreSQL 엔진을 사용한다. Auth 서비스 bootstrap만 가상으로 구성하고 실제 foundation/학교급/RLS/편성 migration의 함수·테이블을 실행한다. 초대용 pgcrypto extension 선언은 이 테스트에서 제외한다. 운영 인증이나 다중 프로세스 잠금 경합의 종합 인수검증을 대신하지 않는다.

## 6. 남은 문제와 이유

1. **기존 인증 기반 E2E 전체:** `.test-secrets.json`과 격리 Supabase 계정이 제공되지 않아 실제 인증→PostgREST→저장 전체 시나리오는 실행하지 않았다. 운영 계정·데이터로 대체하지 않았다. UI 저장 흐름은 실습 저장소, DB 계약은 격리 PostgreSQL로 각각 검증했다.
2. **교육과정 법정 기준 자동 판정:** 학교자율시간·자유학기·정보교육·스포츠클럽 포함관계·학교 유형·시도 지침을 모두 모델링하지 않았다. 이번 수정은 잘못된 학교급 기준 노출과 단위 혼용을 막는 데 집중했다.
3. **기존 잘못 저장된 연계 시수 일괄 복구:** 실제 학교의 의도를 확인하지 않고 다시 계산하지 않는다. 마이그레이션 적용 후 안내를 보고 해당 편성표를 검토·재저장해야 한다. 이전 확정본은 역사적 자료로 보존한다.
4. **이전 운영편제·Excel 가져오기 화면:** v5가 숨긴 이전 모듈은 그대로 유지한다. 특히 초등·고교 Excel 전체 재가져오기 및 학교별 제출 서식은 별도 검증이 필요하다. 중학교 A:Z 원본형의 기존 내보내기→파싱 회귀 테스트는 유지했다.
5. **공식 자료 최신 개정의 자동 적용:** 기존 등록 기준의 법적 완결성을 새로 인증하지 않았다. 이전 학년도/교육과정별 예외와 구형 클라이언트의 버전 없는 확정 API는 후속 이관 범위다.

## 7. 영향과 배포 전 확인

- 학사일정 목표와 수업·평가는 기존 `curriculum_hours`를 계속 참조한다. 새 저장부터 문서와 동일한 학기 계산값이 전달된다. 기존 학사 문서·수업계획·시간표 내용은 직접 변경하지 않는다.
- 운영 반영은 승인 후 **새 SQL migration → 앱 배포** 순서로 진행해야 한다. 새 확정 API는 migration이 필요하다. 구 클라이언트의 save/confirm 함수 서명은 보존했다.
- 새 마이그레이션은 데이터 backfill이 없다. 편성 문서·시수·revision 갱신은 사용자의 저장 한 트랜잭션에서만 실행된다.
- 초등/학점의 원본형 내보내기는 전체 학기 열이 있는 범용 표로 확장된다. 기존 중학교 A:Z 서식은 유지한다.
- 실습 경로는 기존 Preview/local gating 아래에 있으며 운영 빌드 기본값에서는 404다. 브라우저 저장 자료는 가상 학교 데이터뿐이다.

## 후속 수정: 실습 표의 과목 누락

첫 Preview는 입력·저장 동작을 확인하는 국어/창체 두 행의 최소 자료를 사용했다. 실제 학교 편성표의 교과군·여러 과목을 보여주지 못했고, 최초 브라우저 테스트도 이 대표성 부족을 잡지 못했다.

- 별도 `curriculum-fixture.ts`를 만들어 중학교 8개 교과군의 23개 과목과 창체 5개 항목을 제공한다. 기존 `annual-curriculum-2026.ts`의 학교 선택과목과 일반학기 시수를 활용하되 원본 자료·독립 합계·자유학기 조정은 바꾸지 않는다. 2027 실습용으로 재구성한 예시이며 실제 확정 편성안이 아니다.
- 초등은 통합교과 및 사회/도덕·과학/실과·음악/미술을 구분한 12학기 표, 고교는 여러 교과군과 과목을 구분한 학점 표를 제공한다. 초등 배분과 고교 이수 배치는 실습 예시이며 법적 적합성을 인증하지 않는다.
- 새 예시의 학기 총시수는 정수 주당시수와 잔여 조정값으로 나누어 주수 변경에도 온전한 수업시수를 계산한다. 이미 저장한 셀·조정값·버전은 그대로 유지하며 누락된 과목 행만 보완한다. 종전 창체 합계 입력은 별도 행으로 보존한다.
- 회귀 검증에 학교급별 여러 과목, 기존 두 행 문서의 입력 보존, 과학 과목 편집·재조회, 교과/선택/창체의 실제 Excel 다운로드 확인을 추가했다. 운영 학교의 과목 목록이나 시수는 변경하지 않는다.
