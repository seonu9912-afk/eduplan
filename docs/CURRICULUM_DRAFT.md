# 총론 기반 편제 초안

출처: 사용자가 제공한 「(2022 개정) 초·중등학교 교육과정 [별책 1] 총론」, 국가교육위원회 고시 제2026-1호(2026.1.21.) 일부개정 포함. 아래 쪽수는 PDF 뷰어 순번이 아닌 **본문 인쇄 쪽수**입니다.

## 적용 시점

부칙은 2026년 3월 고1·2, 2027년 3월 고3, 2028년 3월 초1·2 적용을 명시합니다. 초등 1~2학년의 ‘건강한 생활’ 신설과 변경 배당표를 2026학년도에 소급하지 않습니다. 이 문서만으로 제공하는 초등 초안은 2028년 이후 입학생용입니다. 이전 입학생의 기존 편성표는 유지합니다. 중·고등학교 초안은 2022 개정 적용 대상인 2025년 이후 입학생용으로 제공합니다.

## 추출한 기준

| 학교급 | 본문 | 합계와 단위 |
| --- | --- | --- |
| 초등학교 | 17~19쪽, 표1 | 1~2학년 1,744시간 / 3~4학년 1,972시간 / 5~6학년 2,176시간 |
| 중학교 | 20~22쪽, 표2 | 교과 3,060 + 창체 306 = 3,366시간, 3년 기준 |
| 일반고 | 24쪽, 표3 | 필수 교과 84 + 자율 이수 90 + 창체 18 = 192학점 |
| 특성화·산업수요 맞춤형고 | 25쪽, 표4 | 보통 교과 64 + 전문 교과 80 + 자율 이수 30 + 창체 18 = 192학점 |

초등학교는 40분, 중학교는 45분 수업을 원칙으로 합니다. 고등학교 1학점은 50분 기준 16회이며 창체 18학점은 288시간입니다. 이 단위를 혼용하지 않습니다. 기존 편성표는 원래 입력 단위인 시수로 남기고 새 고등학교 총론 초안에 학점 단위를 기록합니다.

## 생성 방식과 한계

- 교과군의 기준 합계를 유지하면서 해당 학년군/학교급의 학기 수로 나눕니다. 정수 나머지는 앞 학기에 1씩 더합니다. 이는 학교가 수정할 **배분 출발안**이며 학기별 법정 기준을 뜻하지 않습니다.
- 실제 세부 과목으로 나누기 전이므로 과목명에 `[초안]`을 붙입니다. 고등학교의 ‘자율 이수 (배분 전)’는 실제 과목에 배분할 잔여 학점입니다.
- 기존 편성표가 있는 입학년도에는 생성할 수 없습니다. 생성은 교과군·과목·편성표·입력값을 한 트랜잭션으로 저장합니다.
- 실제 과목으로 나눌 때는 기존 `[초안]` 행의 값을 줄이거나 삭제하여 중복 합산을 피해야 합니다. 과목 삭제는 모든 입학년도에 영향을 주므로 삭제 확인창의 연결 편성표를 검토합니다.
- 창체 영역은 자율·자치, 동아리, 진로로 분류할 수 있으나 영역별 배분, 집중이수, 학교자율시간, 자유학기, 진로 선택, 공통 과목, 정보교육, 스포츠클럽 및 시·도교육청 지침을 모두 자동 판정하지는 않습니다.
- 초등 정보교육 34시간 이상, 중학교 정보교육 68시간 이상, 중학교 학교스포츠클럽 총136시간 등의 추가 검토 항목을 화면에 표시합니다. 법정 적합성 인증 기능은 아닙니다.

## 학사·업무계획 연결

학기 기간은 학사운영에서 변경하고, 작업공간 설정은 학년도 개설·학급 수만 담당합니다. 여름방학 구간으로 1학기 종료일/2학기 시작일을 맞추는 버튼을 제공합니다. 방학은 연간 계획 저장, 학기는 학기 기간 저장으로 각각 반영합니다.

행사 ‘교육활동 영역’은 분류 정보입니다. ‘수업·창체’에서 등록 행사를 가져오면 날짜·명칭·부서·학년별 영역을 채웁니다. 실제 교시를 배정한 뒤에만 시수로 집계하며, 연결된 행사를 업무계획에 중복 표시하지 않습니다.

주간계획은 월~토요일 카드와 공지·협의사항, 월중계획은 달력/목록 보기입니다. 일요일 일정은 월중계획에서 관리합니다. 당직은 기본 미사용이며, 기존 당직 자료가 있는 이전 문서는 설정값이 없을 때 표시를 유지합니다. 사용 해제 시 저장 데이터는 보존합니다. 시간·장소·대상은 선택 입력입니다.
