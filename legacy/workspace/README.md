# EduPlan Workspace v1.7.0 — 편성 정확성·작업 편의성 개선

기존 v1.6.3 검증판의 브라우저 저장소 데이터를 유지하면서 다음 기능을 추가했습니다.

## 이번 변경

- **통합 편성 점검**: 2027학년도 19학급 예시를 포함해 연간 수업일수, 학년별 교육과정 편성 자료, 시간표 배정 627교시와 실제 배정표 비교, 수업 충돌, 부서별 재확인 상태를 읽기 전용으로 함께 진단합니다. 문제가 있는 메뉴로 바로 이동할 수 있습니다. 결과 텍스트 다운로드를 지원합니다.
- **학사행사 변경 영향 미리보기**: 행사 목록 편집창과 행사 빠른 편성 입력 패널에서 변경 전후 학급별 실제 배정 수업 칸, 과목별 변화, 다른 행사와의 중복을 보여줍니다. 실제 기본 시간표를 바꾸지 않습니다.
- **시간표 수업 배정 개선**: 교사별·학급별·전체 표 전환, 전체 표 복사, CSV 다운로드, TSV 붙여넣기 및 검증 후 적용, ID 기준 일부 수정 또는 전체 교체를 제공합니다. 입력 내용이 적용되지 않은 채로 이동할 때 경고합니다.
- **작업 안전성**: 상단 브라우저 저장 상태 표시, 적용하지 않은 배정표·문서·계획의 페이지 이탈 보호, 활동반 추가 시 발생할 수 있던 미정의 상태 참조 해결, 반응형 UI 통합.

## 사용 방법

1. 사이드바 **통합 편성 점검**에서 학년도와 문제 목록 확인.
2. **학사일정 → 행사 빠른 편성**에서 행사 날짜·시수 영역을 수정할 때 **수업·시수 영향 확인** 펼치기.
3. **시간표 → 수업 배정**에서 교사별/학급별 필터, **전체 표 복사 → 엑셀 편집 → 붙여넣기 편집 → 검증 후 적용**.
4. 실제 학교를 위한 공동저장·사용자별 권한은 아직 제공되지 않습니다. 사용 전 관리자 설정에서 JSON 백업을 만드세요.

## 검증

- `npm test`: Node 단위/통합 테스트 108개 통과
- 2027학년도 실증 시나리오: 19학급, 주당 627교시 배정표와 기본 시간표 일치 검증
- JSX/JS 구문 검사(전 컴포넌트) 통과
- Next.js 원격 빌드 및 별도 preview 배포 결과 확인 후 공개

## 주의사항

- 법정 수업일수/시수 판단은 관계 법령과 학교별 교육과정 운영 기준을 별도 검토해야 합니다.
- 실제 학생 개인정보는 입력하지 마세요. 이 시범판은 브라우저별 로컬 저장 구조입니다.
- 행사 영향 미리보기의 시수는 **실제로 배정된 학급 수업 칸**에 한정됩니다. 교육과정 이수시수를 공식 확정하는 계산이 아닙니다.
- 시간표의 한 수업 배정 행을 수정하면 이전 자동편성 미리보기는 무효화됩니다.

## v1.7.3 교사별 수업시수표
- 기본 수업 배정 보기를 교사 × 과목 × 학급 주당 시수 매트릭스로 전환합니다.
- 1~3학년 학급별 수업시수/합계, 고정 과목/교사/합계 열, Enter·Tab 이동, 다중 셀 붙여넣기를 지원합니다.
- 입력은 임시 수정 후 적용하며, 원본 수업 ID와 특별실·연속·공통수업 제약은 보존합니다. 복합 배정 칸은 상세 배정표에서만 수정할 수 있습니다.
- 가상 교사 이름과 기존 19학급 627교시/336배정 자료는 변경하지 않았습니다.


## v1.7.3 교사 수업 부담 기준
- 하루 수업 상한 5교시, 점심 전후 연속수업 3교시 상한(학교별 조정).
- 교사별 월~금 시수 균형 편성 목표, 주별 편차 보고.
- 자동편성 초안은 적용 전 품질 검토. 기존 편성은 자동 삭제하지 않음.
- 숫자는 법정 최대치가 아니라 조정 가능한 앱 기본값.
