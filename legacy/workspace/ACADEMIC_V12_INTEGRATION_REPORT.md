- 이전 독립 검증 탭을 기본 학사일정 화면으로 연결하고, 기존 학사력·행사 편성 화면은 대체 메뉴로 유지.
- 날짜 수정·행사 수정·반복 창체·행사 가져오기 작업 시 이동/닫기 확인 등 변경사항 보호 개선.
- 반복 창체 제외일을 유효 운영 날짜별 체크박스로 선택하도록 개선.
- 공휴일 API 조회 및 적용 전 미리보기, 수동 편집 데이터 보존.
- 복수 일자 행사 종료일 입력 및 수정 사항 반영.
- 주별 수업시수(2단 표제/합계), 반복 창체 활동 영역별 명세, 월별 학사력 6주 출력 등 Excel 서식 개선.
- 2027년 가상 중학교 데이터 기준 교과·창체 기본 집계 테스트 강화.

## 검증 범위의 한계

- 원본 GAS 웹앱과의 브라우저 클릭 흐름 및 Excel 화면/인쇄 양식의 완벽한 픽셀 단위 일치는 아직 입증하지 못함.
- 최신 정식 배포판의 클릭·편집·저장·다운로드 전 과정에 대한 브라우저 E2E 테스트는 수행하지 못함. 따라서 기능별 현장 검수는 계속 필요함.
- 이번 Workspace 미리보기는 브라우저 로컬 저장을 기반으로 하며, 실사용 협업 환경의 서버 DB 및 실시간 다중 사용자 기능은 이번 이식 범위에 포함되지 않음.
- 원본의 세부 교과별 시수와 프로그램 집계 방식의 완전한 동등성은 추가 비교가 필요함.

## 2026-11-15 추가 수정: 최상위 학사일정 메뉴 직접 교체

- `app/page.jsx`의 최상위 `calendar` 메뉴 렌더링을 `CalendarV12Port` 직접 호출로 교체.
- 기존 `CalendarPlanner`의 중복 하위 탭(편성 설정/기존 학사력/행사 빠른 편성 등)을 제거하고, 호환용 import는 새 화면 re-export로 변경.
- 새 화면 내 월간/연간/수업·창체/행사/시수/점검/엑셀은 작업에 필요한 **기능 탭**으로 유지.
- 날짜 편집기의 `onDirtyChange` 미전달 오류를 수정하여 작성 중 이동 확인이 정상 작동하도록 개선.
- 기존 작업공간의 로컬 데이터 포맷·저장 키 및 다른 메뉴 코드는 변경하지 않음.
- 최상위 학사일정 직접 렌더링과 구 UI 제거를 검증하는 회귀 테스트로 기존 테스트를 교체.
