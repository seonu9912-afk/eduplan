## 이번 화면 개편

1. **연간 학사력**을 학사일정의 기본 진입 화면이자 첫 번째 탭으로 변경했습니다.
2. **월간 학사력**을 별도 탭에서 제거하고 **행사 편성** 화면 위쪽에 달력으로 통합했습니다. 아래에 기존 행사 편성 목록·엑셀 등록·편집 기능이 나타납니다.
3. 연간 또는 월간 학사력의 **날짜를 클릭하면 오른쪽 드로어**에서 수업일·공휴일·방학·재량휴업일·요일교체와 비고를 수정하도록 변경했습니다. 닫기·배경 클릭·Escape와 저장되지 않은 변경사항 확인을 지원합니다.
4. 학사일정 화면 상단의 대형 제목·설명·수업일수 카드·공휴일 조회 버튼 및 가상학교 검증용 안내 배너를 제거했습니다. 학년도 선택과 기능 탭만 유지했습니다. 다른 메뉴의 안내 배너는 보존했습니다.
5. **연간 수업일수·1/2학기 수업일·재량휴업일·방학일**은 연간 학사력 아래의 접이식 상세 영역에 배치했습니다. 방학·재량휴업일 일괄 지정 역시 별도 접이식 영역으로 정리했습니다.
6. 공휴일은 해당 학년도에 한 번도 조회하지 않은 경우 **최초 진입 시 자동 반영**합니다. 기존 학교에서 수동 지정한 날짜는 덮어쓰지 않으며, 연간 학사력 내 **공휴일 관리** 영역에서 수동 재조회를 할 수 있습니다. API 실패 시 기존 규칙을 그대로 유지하고 오류를 표시합니다.
7. 시간표와 중복되던 **수업·창체** 탭을 제거했습니다. 해당 구 메뉴에 저장된 `v12Recurring` 데이터는 삭제하지 않았고, 시수 확인의 중복 별도 표시는 제거했습니다. 기존 Excel 출력 기능과 예전 반복 창체 기록은 호환을 위해 남겨 두었습니다.

## 주의 및 잔여 검증

- 브라우저에서 실제 클릭·입력·새로고침을 수행하는 E2E 테스트는 자동화 환경의 외부 DNS 제한으로 수행하지 못했습니다. 서버 렌더링/컴파일/단위 테스트는 통과했습니다.
- 이 미리보기의 저장은 브라우저 기반이며 실시간 공동작업 서버는 이번 범위에 포함하지 않았습니다.
- 이미 학년도 공휴일을 반영한 기존 자료는 접속할 때마다 다시 변경하지 않습니다. 최신 공휴일 목록은 **공휴일 관리 → 다시 조회**에서 갱신할 수 있습니다.
- 구 `v12Recurring` 데이터는 삭제하지 않았습니다. 시간표 메뉴와의 최종 시수·엑셀 출력 중복 검증은 후속 과제입니다.
