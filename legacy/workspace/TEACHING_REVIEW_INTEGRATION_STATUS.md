# EduPlan 교수학습·평가 검토 화면 통합 결과

## 적용 대상과 중요한 제한

- 기준 소스: 사용자 파일 보관함에 보관된 `eduplan-workspace-academic-annual-first.zip` (패키지 버전 1.7.4-v12-port-preview)
- 기존 프로젝트: EduPlan Workspace 학사일정/시간표/서식 데모. 운영 `eduplan-silk.vercel.app`과는 다른 소스 구조이다.
- 이 ZIP은 실제 **코드 통합 결과물**이며 운영 서비스에 배포하지 않았다. 최신 별도 Vercel 미리보기 v1.7.7과의 차이를 그대로 유지하며 해당 배포를 덮어쓰지 않는다.
- 브라우저 로컬 저장소에 작성 내용을 저장한다. Supabase 학교별 공동작성, 교과협의회 심의, 학교 전체 평가계획 취합, 공식 성취수준 불러오기, HWPX 출력은 아직 연결되지 않았다.

## 이번에 실제 연결한 기능

1. EduPlan 왼쪽 메인 메뉴에 `교수학습·평가계획` 추가. 기존 화면과 네비게이션은 보존.
2. 학년도/학년/학기/교과 선택, 영역별 연간 평가계획 표 작성, 학기별 평가영역 표 자동 생성.
3. 루브릭 평가요소/수준별 배점 직접 편집과 실시간 최고점·최하점 검증.
4. 주차별 교수학습 활동 및 `★수행평가 연계` 선택.
5. 학교별 최하점 정확값/범위, 평가시기 검사 정책.
6. 검토 목록에서 해당 항목으로 이동, 경고 검토 사유 기록. 저장·검토 제출은 비차단.
7. 범교과 주제 목표 및 선택 교과의 주차별 편성. 학교 전체 교과 합산은 구현되지 않아 검증 미리보기로 제한.
8. `검증 예시 불러오기`는 9~10월 계획에 9월만 연결하여 월별 검토 경고를 재현한다.
9. 학교 작업공간별 브라우저 저장 키를 유지하므로 기존 데이터 스키마를 변경하거나 삭제하지 않는다.

## 기술적 검증

- `node --experimental-strip-types --test tests/*.test.mjs`: 149 tests passed / 0 failed (원본 142개 + 신규 7개).
- TypeScript 파서의 TS/JSX 문법 진단 오류 0건.
- 별도 npm 의존성을 내려받거나 Next.js 프로덕션 빌드/브라우저 E2E 테스트를 수행하지는 못했다.

## 배포 및 운영 통합을 위한 다음 단계

1. 현재 진행 중인 학사일정 Work의 최신 v1.7.7 이상 소스와 본 ZIP의 변경사항을 충돌 없이 병합.
2. 사용자 실제 운영판 `eduplan`의 `src/components/features/teaching/*` 구조와 데이터 모델에 맞게 UI/검증 코드를 이식.
3. Supabase 사용자/권한/RLS 및 교과별 계획 저장·학교별 정책 연결.
4. 교육평가부 교과 전체 취합, 범교과 학교/학년 전체 시수 합산 및 검토 이력 테이블.
5. HWPX 양식과 공식 성취기준 원문 검증, 확정본 변경 절차.
6. 통합 코드의 실제 Next.js build / E2E / RLS 테스트 후 별도 Preview 배포, 사용자 확인 후 운영 반영.
