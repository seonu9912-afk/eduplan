# EduPlan 학사일정 원본 v12 이식 현황 — 독립 검증 빌드

원본: `AcademicPlannerRedesign_v12.html/.gs` 및 `학사일정_통합관리형_v12.xlsx` (원본 변경 없음). 현재 공개 웹앱은 제목만 읽혀 실제 브라우저 조작 동등성은 검증하지 못함.

## 원칙 및 접근
- 기존 EduPlan `CalendarPlanner`와 다른 모듈을 그대로 유지하고, 하위 탭 **원본 v12 이식 검증**에 `CalendarV12Port`를 추가함.
- `space.academics[year].dayRules` / `space.events`를 유일한 날짜/행사 데이터 원본으로 사용함. Google Apps Script, Google Sheets, Google Drive에 읽기/쓰기 요청 없음.
- `plan.v12Recurring`만 별도 반복 창체 규칙으로 저장함. 기존 `plan.weekly`의 일과/시간표 정보는 참조만 함.
- 실제 학교 2026 데이터는 공개 데모 소스에 포함하지 않았음. 2027년 19학급 가상 자료로 테스트.

## 구현된 기능
- 월간 7열 달력 및 3~다음 해 2월 연간 12열 달력, 월별 수업일수 합계, 색상별 날짜 구분.
- 날짜 한 번 클릭으로 학사일 속성 편집, 별도 행사 칩 클릭으로 행사 편집 (단순 날짜 클릭으로 행사 편성으로 이동하지 않음).
- 단일 날짜의 수업일/공휴일/방학/재량휴업일/주말/요일교체 설정과 해제.
- 방학/재량휴업일 기간 입력, 수업일수 변화 및 행사 영향 미리보기, 확인 후 일괄 적용, 기존 행사/메모 유지.
- 원본의 날짜/학기/요일교체/행사별 1~3학년 영역과 실제 시수 계산, 반복 창체 +시수 별도 계산.
- 교사·학급별 기존 편성은 그대로 보존; 학년별 행사 영역을 교과/자율/동아리/진로/봉사로 구분하여 시간표 반영 로직 확장.
- 반복 창체 CRUD, 제외일 목록 입력, 원본과 유사한 편성 오류 점검, 경고 숨김(이번 화면 세션에 한정).
- 행사 CRUD, 엑셀 행사 일괄 불러오기 및 검토 후 추가, 중복 검사.
- 브라우저 직접 생성 `.xlsx` 출력 4종: 행사목록 1시트, 주별 시수 2시트, 창체 6시트, 월별 학사력 12시트.
- 원본 Google Drive 출력 폴더, 웹 CDN, oauth 없이 자체 `.xlsx`(ZIP/OpenXML) 생성 및 구조 검증.
- 기존 교육과정·시간표·월중주간계획에서 기존 학사일정 데이터 즉시 재사용.

## 아직 원본과의 100% 동등성을 검증하지 못한 항목
- 실제 원본 웹앱의 클릭 순서·스크롤·모달/인쇄 동작은 실행 화면 접근이 되지 않아 자동 브라우저 비교 불가.
- 원본 v12의 모든 출력 Excel 레이아웃(특히 주별 현황 2단 머리글/병합과 창체 각 시트 세부 서식)을 픽셀 단위로 재현하지 못함. 현재는 유효한 XLSX와 유사한 열/표를 제공함.
- 원본 반복창체 '날짜별 체크박스 선택' UI는 현재 제외일 텍스트 입력으로 구현됨. 추가 UX 개선 필요.
- 기존 EduPlan의 세부 교과별 수업시수·실수업 시수와 원본 v12의 요일별 '기본 운영 교시' 집계는 모델 차이가 있어 완벽하게 일치한다고 주장할 수 없음.
- 공휴일 API 재조회는 기존 학사일정 화면의 API 기능을 이용하도록 남겨둠. 새 검증 화면에 별도의 공휴일 버튼은 아직 없음.
- 월중·주간계획 전체의 활동 필드와 원본 학사행사의 모든 메타데이터 매핑은 추가 점검 필요.
- 새 이식 UI의 반응형 E2E 브라우저 테스트, 원본 엑셀 수치와의 1:1 비교는 미완료.
- 테스트 외 실제 다중사용·서버 DB 구현은 현재 EduPlan의 범위 밖이며 브라우저 로컬 저장임.

## 테스트
- 기존 EduPlan 자동 테스트 및 v12 포트 단위/통합 테스트 총 133개 통과.
- 새 JSX/JS 파일 TypeScript 파서 구문 검사 통과.
- 2027년 19학급 가상 데이터 627 주당 수업칸 유지, 원본 일정을 수정하지 않는 리포팅 확인.
- 생성 `.xlsx` 네 종류의 ZIP/Office XML 파싱 및 워크시트 수 검사 통과.
- 로컬 `npm install`은 네트워크 DNS 오류로 실패했으므로 로컬 `next build`는 미실행. 원격 Vercel 빌드 결과를 별도로 확인해야 함.
